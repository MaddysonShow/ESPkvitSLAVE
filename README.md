Проект для ведомого (slave) контроллера ESP32, получает данные по ESP_NOW (аварии), выводит на 4-х строчный текстовый экран (i2c), считывает id карты (RDM6300) и передает на ведомого, который в свою очередь отдает на бэкэнд и если карта легитная квитирует аварию
